# Windows System Information & Troubleshooting

## Objective
Learn how to gather Windows system information and use common troubleshooting tools.

## Commands and Tools Used

### `hostname`
**Purpose:** Displays the name of the computer.  
**Result:** `windows11lab`

### `systeminfo`
**Purpose:** Displays detailed information about the Windows operating system and computer hardware.  
**Result:** Reviewed the OS version, system type, memory, and computer name.

### `ipconfig /all`
**Purpose:** Displays detailed network configuration information that can help troubleshoot connectivity problems.  
**Result:** Reviewed the IPv4 address, subnet mask, default gateway, DNS servers, and DHCP settings.

### `ping 8.8.8.8`
**Purpose:** Tests basic network connectivity using an IP address.  
**Result:** Received replies, confirming network connectivity.

### `ping google.com`
**Purpose:** Tests internet connectivity and DNS name resolution.  
**Result:** Received replies, confirming connectivity and DNS resolution.

### Task Manager
**Purpose:** Monitors running processes and system resource usage.  
**Result:** Reviewed CPU, memory, disk, and network activity.

### Device Manager
**Purpose:** Displays hardware devices and their drivers and can help identify hardware or driver problems.  
**Result:** Reviewed the VM's display adapter, network adapter, disk drive, and processor devices.

### Event Viewer
**Purpose:** Displays Windows system events and helps troubleshoot crashes, services, drivers, and other system problems.  
**Result:** Reviewed the System log and identified informational, warning, and error events.

### Windows Services
**Purpose:** Displays background services that support Windows and installed applications.  
**Result:** Reviewed system services including DHCP Client, DNS Client, Windows Update, and Windows Event Log.

## What I Learned
I learned how to check system information, network settings, connectivity, hardware, event logs, and Windows services.
